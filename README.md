Carrito de Compras
Clasificación de las entidades por dominio
El proyecto Carrito de Compras es una aplicación para gestionar pedidos de comida a domicilio. Las entidades se clasifican en tres dominios: actores, catálogo y transaccional.
1. Dominio de actores
Son las entidades que representan a las personas que participan en el sistema.
Usuario: persona que utiliza la aplicación para realizar pedidos.
Repartidor: persona encargada de entregar los pedidos a los usuarios.
2. Dominio de catálogo
Contiene la información de los restaurantes y los platos disponibles para los usuarios.
Restaurante: almacena el nombre, la categoría, la dirección y el teléfono del restaurante.
Plato: contiene el nombre, la descripción, el precio y la disponibilidad de los platos ofrecidos por los restaurantes.
3. Dominio transaccional
Incluye las entidades que registran las operaciones realizadas dentro de la aplicación.
Pedido: registra la información de cada pedido, como la fecha, el usuario, el restaurante, el repartidor y el estado.
Detalle_Pedido: registra los platos incluidos en cada pedido, la cantidad solicitada y el precio de cada plato.
